# 青境智衡

> **高原幼畜圈舍氨气感知与动态通风调控装置**
> 面向青海高原中小养殖户的百元级幼畜暖棚环境监测与本地决策系统。

[在线演示](https://runner-cpu.github.io/QJZH/) · [规则库文档](knowledge-base-rules.md)

## 项目简介

青境智衡聚焦犊牦牛、藏羔羊等幼畜冬季越冬暖棚场景，针对高原低压导致通用氨气传感器漂移、保温与降氨难以兼顾、基层运维门槛高等问题，提供**实时采集、高原补偿、离线规则决策与可视化回溯**的一体化方案。

项目面向青海海拔 **2200-3500 m** 的中小型畜禽养殖场，以犊牦牛和藏羔羊暖棚为核心，保育仔猪舍饲为补充。装置可在本地主控侧完成核心计算，不依赖公网。

## 背景与痛点

青海牦牛存栏量常年约 600 万头、藏羊存栏量超千万只；传统农牧户占全省农牧业生产经营主体的 95.6%。冬季暖棚舍饲是幼畜培育的重要场景，也放大了环境调控问题。

| 核心痛点 | 现场表现 | 项目应对 |
| --- | --- | --- |
| 保温与降氨失衡 | 密闭暖棚保温会造成氨气积聚，贸然通风又可能诱发冷应激 | 结合午间 12:00-14:00 温度窗口，输出短时微通风建议 |
| 通用设备高原失效 | 2200-3500 m 区域气压较平原衰减约 20%-30%，平原标定设备误差可达 35%-40% | 气压-温湿度双维度非线性补偿 |
| 运维门槛不匹配 | 设备复杂、上门维修半径大，存在“买得起、用不好、修不了”问题 | 模块化硬件、本地离线决策、局域网页面展示 |

## 产品与技术方案

### 四层离线架构

```text
感知采集 -> 算法校准 -> 决策输出 -> 可视化展示
DHT22 / MQ-135 / BH1750 -> 高原补偿模型 -> 本地规则库 -> 局域网网页看板
```

所有核心计算可在本地主控侧完成，不依赖公网，适配牧区弱网络环境。基础版本预留标准继电器控制接口，后续可连接通风设备，逐步升级为自动调控方案。

### 核心功能

- 📊 **实时环境监测**：采集温湿度、氨气、光照，展示实时数值、风险状态和趋势曲线。
- 🧠 **智能通风决策**：按本地畜牧规则匹配风险等级与操作建议，平衡降氨与保温需求。
- 🗂️ **数据回溯导出**：保存采样记录与快照，为养殖优化和兽医研判提供环境参考。
- 🔧 **闭环执行演示**：展示通风扇、保温设备及通风窗口等模拟执行状态。

### 硬件选型

| 模块 | 作用 | 设计要点 |
| --- | --- | --- |
| ESP32-S3 | 主控与本地网页服务 | 负责采集、计算与展示 |
| DHT22 | 温湿度采集 | 合理读取间隔，探头可加防溅保护 |
| MQ-135 | 氨气响应 | 预热老化，使用温湿度与气压因素校正漂移 |
| BH1750 | 光照采集 | 通过 I2C 接口参与综合环境评估 |
| 0.96" OLED | 本地状态提示 | 显示设备端状态和预警信息 |
| MB102 | 供电模块 | 为不同电平模块提供稳定供电 |

## 核心技术亮点

### 🔬 高原双维度补偿算法

- 以**气压 + 温湿度**双变量构建非线性补偿模型，面向青海高原低压环境修正气敏传感器零点漂移。
- 依托传感器参数与本地气象数据进行理论建模，无需额外加装气压传感器。
- 理论测算中，将通用平原传感器 **35%-40%** 的监测误差优化至 **10% 以内**；后续将通过样机与实地数据进一步标定参数。
- 网页以原始/补偿后氨气对比条形图和补偿系数指示器展示这一过程。

### 🧠 本地轻量化知识库决策引擎

- 不依赖外部 AI 模型或 API，规则、依据和输出均在本地可追溯。
- 结合固定畜牧学规则与青海冬季养殖经验，按优先级完成风险判断。
- 氨气 **15 ppm** 阈值从严参考《NY/T 388-1999 畜禽场环境质量标准》中保育仔猪相关要求。
- 对高氨风险优先给出 12:00-14:00 的短时通风建议，并限制单次温度降幅不超过 3℃。

| 优先级 | 触发条件 | 典型行动 |
| --- | --- | --- |
| 一级警报 | 氨气 > 20 ppm | 强排通风、疏散至安全区域、持续复测 |
| 警告 | 氨气 > 15 ppm | 午间短时通风 5-10 分钟，检查垫料与粪污 |
| 复合预警 | 湿度 > 80% 且氨气 > 10 ppm | 清粪、换干燥垫料、延长午间通风 |
| 低温注意 | 温度 < 0℃ | 启动保温并压缩通风时长 |
| 正常 | 未触发以上条件 | 维持管理与定期巡检 |

### 💡 成本与落地创新

以算法校准替代高成本专用检测硬件，基础硬件理论成本控制在 200 元以内；传感器、主控与供电均为可替换模块，降低后期维护与基层使用门槛。

## 市场与竞争分析

### 目标用户

1. **核心 C 端**：西宁、海东东部农业区的中小型家庭牛羊养殖场，重点服务犊牦牛、藏羔羊越冬培育需求。
2. **次级 B 端**：农牧类院校、区县基层畜牧兽医站，用于教学实训与养殖环境普查。
3. **渠道合作方**：乡镇饲料、兽药和农资门店，提供代销、备件更换与基础服务。

| 方案 | 优势 | 局限 |
| --- | --- | --- |
| 大型商用环控系统 | 功能完整、可自动调控 | 数千至万元级成本高、运维复杂、未必适配高原 |
| 消费级/开源传感器 | 成本低、易购买 | 缺少高原补偿和养殖决策，调试门槛高 |
| 传统人工经验 | 无设备投入 | 判断滞后、误判风险高 |
| **青境智衡** | 高原算法、离线易用、模块化维护、通风决策 | 当前处于理论方案阶段，待完成实地测试 |

项目以高原专属校准、百元级成本、轻量化运维和本地服务形成错位优势，填补中小养殖户幼畜暖棚环境管理的细分空白。

## 商业模式

采用“**硬件引流 + 服务盈利**”的轻资产路径：

- **硬件销售**：以亲民定价覆盖基层市场，作为获客入口。
- **耗材配件**：可插拔氨气传感器等模块形成复购服务。
- **增值服务**：季度环境评估、养殖优化建议、合作门店权益。
- **机构定制**：面向院校实训与基层畜牧站提供配置和数据服务。

渠道采用“直销 + 农资门店代销 + 机构合作”并行模式，不自建重资产生产线，聚焦算法、服务和市场验证。

## 快速开始

### 在线查看

访问 [https://runner-cpu.github.io/QJZH/](https://runner-cpu.github.io/QJZH/) 即可进入演示看板。

### 本地运行

该项目是静态单页应用，可直接用浏览器打开 `index.html`。为避免部分浏览器对本地脚本加载的限制，也可在本目录启动任意静态文件服务器。

```bash
npx serve .
```

演示时可使用顶部的场景模拟切换、暂停/继续、深浅主题与语言切换；点击“保存数据快照”可将当前数据与决策结果加入回溯列表。
