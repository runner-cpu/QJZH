# 青境智衡公开发布质量与原创保护设计

**日期：** 2026-09-28
**状态：** 已获用户批准，进入实现阶段

## 目标

本轮将把青境智衡整理为可公开维护、可追溯发布、可安全试用的静态数据服务演示，同时清除公开文件中与项目无关的背景信息，并以清晰、可执行的授权条款保护原创代码、模型参数、界面文案和视觉资源。

## 已确认的边界

- 不修改 knowledgeBase.js、decisionEngine.js、compensator_engine.js、model_weights.js、simulator.js 五个锁定算法文件的算法内容。
- 保留六视图 SPA、中文/英文/藏文、CSV 与人工录入、本地存储降级、报告预览、打印、移动端布局和 GitHub Pages 发布能力。
- 公开文档、界面文案、报告文案和生成器不得出现学校、比赛、参赛、课堂、答辩或类似背景信息。
- 不使用禁用右键、阻断键盘、干扰屏幕阅读器、恶意反爬或破坏性混淆等措施。
- 所有导入数据仍只在浏览器本地处理；系统继续明确说明它不是硬件控制器、法定检测工具或动物诊疗系统。

## 方案结构

### 1. 公开内容治理

建立统一的公开内容词表和验证器，扫描 README、Markdown、HTML、JavaScript、许可证和发布产物。通用角色文案将使用“区域分析”“运营协作”等中性表达；报告水印只保留“演示数据”和安全边界。生成器中的源文案与生成结果同时更新，避免下次自动生成重新引入禁用词。

### 2. 原创保护与溯源

采用“保留所有权利”的定制许可：允许查看代码、运行本地副本和进行内部评估，但未经书面许可不得复制、改编、再发布、销售、移除署名或将模型参数用于衍生服务。新增：

- COPYRIGHT.md：权利范围、允许行为、禁止行为、第三方依赖和联系入口。
- ORIGINALITY.md：原创组成、受保护文件边界、版本标识和侵权报告方式。
- originality-manifest.json：受保护源文件的 SHA-256、文件用途和清单版本。
- scripts/verify-originality.js：验证清单、许可证标题、必要署名和公共文件未被意外加入内部内容。

页面、报告和 build_info.js 保留低干扰项目标识、版本和提交哈希。该措施提供法律通知和证据链，不声称可以阻止任何人复制网页源码。

### 3. 输入与 DOM 安全

在 dataImport.js 增加文件大小、行数、字段数量和单字段长度限制；拒绝空表头、重复必需表头、异常长站点标识和超限 CSV，保留现有原型污染防护、时区时间校验和派生字段重算。继续使用转义函数或 textContent 写入不可信数据，并为导入、报告和机构视图增加回归测试。

### 4. 发布完整性

将原创校验和公开内容扫描接入 verify-deployment.js 与 GitHub Actions；scripts/build-pages.js 的 allowlist 增加公开版权与安全文档，仍禁止把测试、内部工作记录和备份复制到 Pages。发布前必须重新生成知识库文档、构建 dist、运行完整测试和线上入口检查。

### 5. 文档体系

README 将补充快速开始、六视图说明、CSV 字段字典、数据生命周期、模型适用范围、隐私与安全、常见故障、发布流程和授权边界。新增用户指南、数据字典、安全说明和发布清单。所有公开文档使用中性产品背景，不包含任何学校或比赛线索。

## 可验证结果

- Node 测试覆盖公开内容治理、许可条款、清单哈希、CSV 限制和 DOM 输出安全。
- verify_compensator.js 与 verify-deployment.js 在源码目录和 dist 均通过。
- 生成后的 Pages 只包含 allowlist 文件，并包含版权说明、原创清单和构建信息。
- GitHub Actions verify 与 deploy 成功，线上首页、自检页、机器人规则、站点地图和版本信息返回 200。
- 公开文件禁词扫描为零命中；未向文档写入学校、比赛或个人隐私信息。
