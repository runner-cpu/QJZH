# 用户指南

## 1. 开始使用

打开在线页面或在本地静态服务器中运行项目。推荐使用最近两个大版本的 Chromium、Edge、Firefox 或 Safari，并允许页面使用浏览器本地存储。直接双击 index.html 也能浏览静态界面，但部分浏览器会限制文件选择、窗口打印和跨文件读取。

本地预览命令：

    npx serve .

然后访问本地服务器显示的地址。

## 2. 六个视图

| 视图 | 入口 | 用途 |
| --- | --- | --- |
| 总览 | #/overview | 查看当前站点、传感器读数、趋势和最近记录 |
| 数据接入 | #/data | 导入 CSV、人工录入、加载示例和清除本地记录 |
| 高原校准 | #/algorithm | 对比原始读数、校准读数、输入范围和置信度 |
| 智能决策 | #/decision | 查看风险等级、建议窗口、规则 ID 和解释链 |
| 机构版 | #/institution | 按站点或畜种筛选多圈舍摘要并生成报告 |
| 环境报告 | #/report | 按日期范围生成三语报告、预览、打印或保存 PDF |

导航使用 hash 路由。刷新页面会保留当前视图；键盘进入新视图时，标题会自动获得焦点。底部移动导航支持横向滚动，屏幕阅读器可读取当前页面状态。

## 3. 数据接入

### 示例数据

点击“加载示例数据”会覆盖当前示例站点记录，避免重复点击产生重复样本。示例数据仅用于体验导入、校准、趋势、风险和报告链路。

### CSV 导入

下载模板，填写必需字段后选择文件。导入器会逐行校验：缺少字段、数值越界、站点标识、时间格式、字段长度和记录数量。合法记录会按站点与时间戳去重；CSV 中的校准值、风险等级等派生字段不会被信任，系统会重新计算。

### 人工录入

填写时间戳、站点、海拔、温度、湿度、原始氨气和设备型号。时间必须包含时区偏移，例如 2026-01-15T08:00:00+08:00。保存前系统显示质量等级和输入置信度。

## 4. 机构视图

机构视图默认显示五个确定性的演示圈舍。可以切换畜牧站、区域分析和合作社三种分析视角，也可以选择从本地记录导入。筛选只影响当前列表，不修改原始记录。

## 5. 报告与打印

报告默认统计最近 90 天。开始日期和结束日期均按 Asia/Shanghai 的完整自然日处理；反向日期会被拒绝。报告包含风险分布、校准氨气趋势、舒适区占比、温度范围、建议次数、来源构成、模型/规则版本和数据质量统计。

浏览器允许弹窗时会打开打印窗口；如果弹窗被阻止，当前页面会显示可复用预览。选择浏览器的“打印”并将目标设为 PDF 即可保存。报告会标注演示数据边界，不是法定检测报告。

## 6. 主题、语言与重置

页面支持中文、英文和藏文，以及深色/浅色主题。偏好保存在浏览器中，不会上传。点击“重置演示数据”或数据页的“清除本地数据”只删除 QJZH_ 业务记录，不删除主题和语言偏好。

## 7. 存储降级

系统按 localStorage、sessionStorage、内存的顺序选择存储。浏览器隐私模式、配额不足或策略阻止写入时，页面会明确显示当前模式。内存模式只在当前页面会话有效，关闭或刷新页面后记录会消失。

## 8. 常见问题

- 看不到导入记录：检查文件是否包含模板中的必需字段，并确认时间带时区。
- 报告为空：扩大日期范围，或先导入/加载样例数据。
- 页面图表空白：检查浏览器是否能访问 Chart.js；脚本不可用时页面会切换到 Canvas 回退。
- 语言切换后仍有旧文字：刷新当前视图，系统会重新渲染动态状态和图表摘要。
- 需要保留数据：在清除或切换浏览器前导出原始 CSV；本项目不提供云端备份。
